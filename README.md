# Roast the Smart Fridge: One Line, Best Laugh Wins

A one-line roast of the smart fridge I share a house with: it shows me ads for milk while I'm staring at the milk — like a waiter reading the menu to the chef.

The program writes the roast to `/output/entry.txt`.
